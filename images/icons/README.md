# Icons

Using icons in diagrams and documentation can improve:
* Readability
* Recognition
* Identifiability
* Comprehesion
* Knowledge Retention
* Knowledge Synthesis

Definition


## Readability

Variance in visuals breaks monotony (blurring of everything into sameness) and improves readability.

## Recognition

Explanation and context can be instantaneous when the reader recognizes an icon.

## Identifiability

Identifiable visual queues like icons can aid the reader in finding or referring to things faster.

Example,

>Reader:  [sees and immediately identifes Akamai logo in upper left]
